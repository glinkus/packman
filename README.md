# Pacman – Object-Oriented Design Course Project

This project is a **Java implementation** of the classic Pacman game, created as a university assignment for the *Object-Oriented Program Design* course. The main goal was to apply and demonstrate multiple design patterns in a practical, game-based scenario.

---

## Project Overview
* **Language:** Java
* **Type:** University team project
* **Focus:** Practical use of object-oriented design patterns
* **Structure:** Each folder in the project represents a specific design pattern implementation.

---

## My Contributions
I implemented the following design patterns to handle various game mechanics:

### **Structural & Creational Patterns**
* **Sound Adapter:** Adapts the game sound system to a unified interface for consistent audio playback.
* **Builder:** Used for the systematic creation of the game maze, allowing for flexible level design.
* **Bridge:** Separates the sound abstraction from its implementation, allowing for independent development of audio features.

### **Behavioral Patterns**
* **Observer:** Implemented for collision observation, triggering specific audio responses when Pacman interacts with game objects.
* **Chain of Responsibility:** Processes game events through a sequence of handlers to decouple event triggers from their outcomes.
